# Reham Kariya University Website

A simple university website made with HTML, CSS, and JavaScript for my Website Assignment.

**Name:** Syeda Sumbul Faisal | **Student ID:** 66552

## Description

A single-page website for a fictional university. It has a hero banner, about section, departments, campus picture, an admission inquiry form (with JavaScript validation), and contact details.

## How to Run

1. Download the project from https://github.com/syedasumbulfaisal13/AICT-WEBSITE (Code → Download ZIP) and unzip it.
2. Double-click `index.html` to open it in your browser.

Keep the `images` folder next to `index.html` so the pictures show.
